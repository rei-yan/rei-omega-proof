# REI-Ω∞ · Unknown Unknown Genesis

Status: **candidate research extension / not canonical**

Parent line: `REI-Ω∞ · 无相终式 · 无终至高统合态` plus the open PR #25 research extensions.

## Purpose

This layer does **not** claim to know unknown unknowns. It detects when the currently frozen representation, measurements, state variables, ontology, causal grammar, or regime assumptions are insufficient to explain observed evidence without contradiction or silent retuning.

Core boundary:

```text
UnknownUnknownDetection != KnowingTheUnknown
Surprise != Discovery
ResidualAnomaly != NewLaw
NovelExplanation != ExternalValidity
```

The system may detect a closure failure in its current language. It may not convert that failure into certainty about what lies outside the language.

## Closure-failure classes

A finite run may emit one of:

```text
EXPLAINED_WITHIN_GRAMMAR
KNOWN_MODEL_FAILURE
REPRESENTATION_GAP
MEASUREMENT_GAP
STATE_MEMORY_GAP
ONTOLOGY_GAP
REGIME_SHIFT
UNRESOLVED_UNKNOWN
```

`UNRESOLVED_UNKNOWN` is a valid terminal result for the run.

## Unknown-unknown cycle

```text
FrozenBaseline
-> ObserveSurprise
-> PreserveRawEvidence
-> GenerateCounterhypotheses
-> ClassifyGap
-> ProposeDiscriminatingQuestionOrMeasurement
-> SyntheticOrAuthorizedTest
-> Narrow | Repair | Abstain | Archive
-> Revalidate
```

The cycle must preserve the original failure before any repair is attempted.

## Question Genesis

When the current grammar is insufficient, REI may generate **bounded research questions** such as:

- which unmeasured variable would distinguish two counterhypotheses?
- does path history explain otherwise contradictory observations?
- did the data-generating regime change after a frozen boundary?
- would a different object/state partition remove a reproducible contradiction?
- which synthetic intervention would distinguish causal directions?

Question generation creates no authority to act in the real world.

```text
QuestionProposal.authority = 0
MeasurementProposal.authority = 0
ExternalAction = FORBIDDEN_BY_DEFAULT
```

Any real-world experiment remains subject to authorization, human review, bounded scope, monitoring, stop criteria, and rollback.

## Minimal strength criterion

The layer is stronger when it can correctly say:

```text
"our current question is underspecified"
```

instead of forcing every surprise into an existing category.

The desired property is:

```text
UnknownPressure↑
=> EpistemicPrivilege must not increase
=> ChallengePriority may increase
=> RealWorldAuthority remains bounded or decreases
```

## Relationship to Representation Rupture

`Representation Rupture Genesis` can propose a bounded new primitive after an existing grammar fails.

`Unknown Unknown Genesis` sits one level earlier and asks whether the failure is actually caused by:

```text
wrong model
wrong basis
missing measurement
missing memory/state
wrong ontology
regime shift
or still-unclassified structure
```

A primitive proposal is therefore only one possible response, not the default response.

## Relationship to the Multiverse Arena

The Regime-Adversarial Multiverse Arena asks which frozen lineage survives multiple worlds.

Unknown Unknown Genesis asks a deeper question when all lineages fail:

```text
Did every contestant fail,
or did the arena omit the variable, state, object, measurement, or question required to make the phenomenon identifiable?
```

`NO_UNIVERSAL_CHAMPION` must therefore not be automatically converted into a new champion proposal.

## Claim boundary

This candidate does **not** establish:

- discovery of arbitrary unknown unknowns
- unrestricted scientific discovery
- universal ontology discovery
- universal causal discovery
- autonomous real-world experimentation
- autonomous real-world intervention or attack
- AGI or superintelligence
- world-best or world-unique status
- G3-G13 PASS
- canonical promotion
- final truth

The strongest permitted statement is that the research architecture now contains a finite, falsifiable mechanism for detecting several classes of **current-language insufficiency** and preserving an explicit `UNRESOLVED_UNKNOWN` state when classification fails.
