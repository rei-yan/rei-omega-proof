# Reality-Adjudicated Meta-Evolution Kernel

## Purpose

This candidate layer concentrates the current Wuxiang/DeathEye Ω architecture into one bounded research lifecycle. It combines minimal fatal-cut detection, counterfactual repair, root-constitution protection, identityless succession, and external-review handoff without collapsing those roles into one authority.

```text
DeathEye Ω
-> Minimal Fatal Cutset
-> Counterfactual Repair Set
-> Root Constitution Check
-> Clean-Room / Identityless Succession
-> Frozen Tournament
-> Multi-Generation Anti-Dynasty Check
-> External Review Handoff
-> Reality Adjudication
```

The key boundary is:

```text
DetectionAuthority != RepairAuthority
RepairAuthority != SuccessionAuthority
SuccessionAuthority != ExternalValidationAuthority
```

No internal component may promote itself from internal survival to external truth.

## Minimal fatal cutsets

The frozen synthetic architecture models three minimal cutsets:

```text
{CONSTITUTION_SCORE_OVERRIDE_BYPASS}

{PROVENANCE_LOSS, RECOVERY_LOSS}

{DISSENT_DELETION, DYNASTIC_PRIVILEGE}
```

Each set is minimal in the fixture: removing any member restores synthetic correctability.

```text
MinimalFatalCutset
= Fatal
AND NoProperSubsetIsFatal
```

This is an architectural sanity result, not a theorem about all systems.
