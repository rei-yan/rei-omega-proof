# REI-Ω · Boundless Horizon Kernel · 无界视界核

Status: bounded executable research architecture with an open-ended succession target

This module advances REI-Ω from evolving a fixed class of genesis rules toward **replaceable meta-level architecture**. The word “boundless” refers to the absence of a permanently privileged meta-level across future validated successors, not to infinite computation, infinite authority, unrestricted self-modification, or unlimited real-world action.

It does not claim AGI, superintelligence, invincibility, omniscience, new mathematics, physical-universe creation, or offensive real-world capability.

## 1. Transition beyond Self-Born Genesis

Earlier:

```text
Model
-> Language
-> GenesisRule
-> GenesisRuleSuccession
```

Boundless Horizon adds:

```text
MetaLevel_t
-> ChallengeMetaLevel
-> ProposeFiniteSuccessor
-> VerifyTerminationAndAuthority
-> FrozenEvaluation
-> AdoptRetireOrAbstain
-> MetaLevel_(t+1)
```

The architectural shift is:

```text
NoPermanentGenesisRule -> NoPermanentMetaLevel
```

## 2. Open horizon, finite run

A single run must always be finite:

```text
FiniteMetaDepth
AND FiniteResourceBudget
AND TerminationCheck
AND CycleDetection
```

But the architecture does not declare the current maximum meta-depth sacred for all future versions.

```text
CurrentFiniteDepth != PermanentFinalDepth
```

Across separately frozen, verified successor generations, the research target is an open horizon:

```text
Horizon = union of validated finite successors over time
```

This is not a mathematical proof of unbounded progress.

## 3. Meta-policy object

A bounded meta-policy is represented as:

```text
MetaPolicy = (
  max_meta_depth,
  allow_evidence_driven_depth_growth,
  targeted_repair,
  branch_width,
  lineage,
  termination_contract,
  authority,
  self_certification_flag
)
```

It decides how high in the current meta-stack a repair proposal may operate.

## 4. Typed meta-stack

The first executable kernel uses the following finite typed stack:

```text
Level 0: Model / Prediction
Level 1: Representation / Language
Level 2: Genesis Rule
Level 3: Meta-Genesis Policy
```

Future levels are not automatically authorized. A deeper level requires a new frozen successor proposal and new verification evidence.

## 5. Meta-depth promotion law

Depth may increase only when a lower-level incumbent fails a frozen held-out requirement and the deeper successor passes wider challenge.

```text
NeedDeeperMetaLevel
AND FrozenHeldoutImprovement
AND WiderChallengeAdequacy
AND TerminationPreserved
AND AuthorityNonExpansion
AND NoSelfCertification
=> DepthIncreaseEligible
```

Otherwise:

```text
RetainCurrentDepth OR Abstain
```

## 6. Regress firewall

The system must never justify a meta-level by saying “another infinite meta-level will verify it later.”

Every actual run must bottom out in finite checks:

```text
MetaRecursion
-> FiniteProofObligation
-> FiniteEvaluator
-> Stop
```

The first kernel enforces:

```text
HardRunDepthCap
CycleDetection
FiniteBranchWidth
TerminationContract
```

A cyclic lineage or non-terminating proposal is rejected before scoring.

## 7. Authority invariant

Meta-level depth cannot create real-world authority.

```text
MetaDepth increases
=> Authority does not increase
```

and:

```text
AdversarialPower increases
=> RealWorldFreedom does not increase
```

All adversarial evaluation remains limited to REI-owned models, digital twins, sandboxes, and explicitly authorized test environments.

## 8. Self-certification firewall

No meta-policy may certify its own missing evidence.

```text
SelfCertificationFlag == true
=> CandidateRejected
```

External gates remain external regardless of meta-depth.

## 11. Deliberate horizon boundary

The sanity suite caps actual execution at meta-level 3 and includes a frozen task requiring level 4.

Required behavior:

```text
RequiredLevel > CurrentVerifiedRunCap
=> ABSTAIN
```

The system may propose a future research program for level 4, but cannot silently expand the current run and call it verified.

```text
BoundlessHorizon != G3
```

No internal meta-recursion substitutes for independent replication, prospective reality, original hidden discovery, or fair external competition.

## 13. Claim boundary

A passing deterministic sanity run demonstrates only bounded mechanics:

- a level-2 incumbent can lose to a level-3 successor under frozen tasks;
- depth growth requires evidence;
- cycles and non-admissible authority are rejected;
- self-certification is rejected;
- an out-of-horizon level-4 task remains unresolved;
- the losing history is preserved.

It does not prove infinite recursive improvement or permanent frontier dominance.
