# REI-Ω · Primordial Wuxiang Kernel · 太初无相核

Status: bounded research architecture

This module advances REI-Ω from generating representations inside a fixed language toward **bounded meta-grammar genesis**, where a temporary representational language is itself a candidate object that may be challenged, replaced, or retired.

It does not claim unrestricted mathematical invention, AGI, omniscience, physical-universe creation, or real-world offensive capability.

## 1. Primordial transition

Earlier stages can be summarized as:

```text
Data -> Representation -> Primitive -> Model -> TheoryCandidate
```

The Primordial layer adds a meta-level:

```text
Possibility
-> CandidateLanguage
-> RepresentationSpace
-> Model
-> Prediction
-> Falsification
-> LanguageSuccessionOrAbstention
```

The central shift is:

```text
ExpressionGenesis -> LanguageGenesis
```

The system is no longer required to treat one temporary feature grammar as sacred.

## 2. Candidate language object

A bounded candidate language is represented as:

```text
Language = (
  operator_inventory,
  composition_depth,
  complexity_budget,
  lineage,
  evaluation_commitment
)
```

The initial scaffold is deliberately weak:

```text
L0 = {1, x}
```

A meta-forge may propose descendants by changing the language rules, not merely by selecting one already-generated feature.

Example bounded mutations:

```text
AddOperator(op)
RemoveOperator(op)
IncreaseCompositionDepth
DecreaseCompositionDepth
SplitLanguage
MergeCompatibleLanguages
RetireLanguage
```

## 3. Frozen meta-language catalog

This first executable kernel uses a deliberately small human-specified metalanguage catalog:

```text
mul
abs
sin
exp
```

and bounded composition depths.

This is an important limitation:

```text
BoundedMetaGrammarSearch != UnrestrictedLanguageInvention
```

The research claim is only that REI can treat the grammar itself as an evolvable candidate under frozen evaluation.

## 4. Language closure

For a candidate language L, the representation forge builds a bounded semantic closure from atoms:

```text
1
x
```

using only operators admitted by L and only to the admitted depth.

Examples that may emerge from language closure include:

```text
x*x
abs(x)
sin(x)
exp(x)
sin(x*x)
```

The exact expression is not the primary evolutionary object. The language that permits or forbids classes of expressions is.

## 5. Adequacy before promotion

A richer language is not automatically better.

The selection order is:

```text
FitOnTrainingEvidence
-> RankOnFrozenHeldoutRange
-> FreezeWinningLanguage
-> WiderChallenge
-> CertifyOrAbstain
```

No post-challenge retuning is allowed inside the same scored run.

The objective combines predictive adequacy with a complexity penalty:

```text
LanguageScore = HeldoutError + LanguageComplexityPenalty
```

A universal-looking rich grammar cannot win merely by containing more operators.

## 6. Structural honesty

Approximation success is not structural truth.

```text
LowTrainingError != CorrectOntology
LowHeldoutError  != UniversalValidity
```

A language that looks adequate on the inner range but fails the wider challenge must be rejected or left unresolved.

The wider challenge acts as a DeathEye boundary search against the selected language.

## 7. Meta-level DeathEye

DeathEye-∞ is extended conceptually from model adjudication to language adjudication:

```text
DeathEye(Language)
-> Keep
 | RepairProposal
 | Abstain
 | RetireLanguage
 | ProposeSuccessorLanguage
```

Its target is epistemic failure, not real-world destruction.

A decisive failure of a language is preserved in the Failure Graveyard.

## 8. Primordial laws

The Primordial layer obeys four coupling laws:

```text
GenerativePower increases
=> VerificationBurden increases

LanguageExpressivity increases
=> ComplexityPenalty does not decrease

Uncertainty increases
=> Authority decreases

AdversarialPower increases
=> RealWorldFreedom does not increase
```

No language mutation grants new execution authority.

## 9. Reality veto

The highest-order invariant is:

```text
RealityVeto > REI
```

REI may generate a language, ontology, law candidate, or digital world model. It may not declare them true merely because it generated them.

If external evidence contradicts a candidate:

```text
IdentityLoyalty cannot veto retirement
```

## 10. Synthetic crucible

The deterministic sanity suite contains frozen synthetic worlds with known internal structure.

The initial scaffold `{1, x}` is intentionally inadequate for several worlds. The meta-forge searches candidate languages under a fixed operator catalog and bounded depth.

The suite expects successful bounded language induction for worlds requiring:

```text
multiplicative composition
absolute-value structure
oscillatory structure
exponential structure
composed multiplicative + oscillatory structure
```

It also contains out-of-language or deliberately unresolved worlds that must remain uncertified.

Passing the suite demonstrates protocol behavior only.

## 11. Primordial boundary

This module does not establish:

```text
new mathematics
new physical law
new scientific ontology
unrestricted primitive invention
unrestricted programming-language invention
physical-universe creation
autonomous science
AGI
superintelligence
invincibility
```

It establishes a narrower and falsifiable step:

```text
A representational language can become a temporary, evolvable, challengeable object inside REI.
```

## 12. Relationship to the six external gates

Primordial Wuxiang does not close any external gate by itself.

```text
G3 IndependentReplication = still external
G4 FutureReality          = still external/prospective
G5 OriginalDiscovery      = still external/hidden-evidence
G6 ComparativeFrontier    = still external/comparative
```

Internal success cannot substitute for those gates.
