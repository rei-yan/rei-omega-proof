# REI-Ω∞ · Discovery Genesis Stack

Status: candidate research extension / not canonical

Parent: `Unknown Unknown Genesis`

This layer turns unresolved or classified knowledge failures into bounded proposals for what to measure, what problem to formulate, which hypotheses should compete, and whether a candidate discovery lineage is even ready for an externally hidden test.

It does **not** claim autonomous discovery, G5 PASS, AGI, universal science, or authority to perform real-world experiments.

## Core reversal

Earlier layers ask whether a model survives evidence.

This layer asks whether the *question, measurement, and hypothesis ecology* are good enough to create decisive evidence.

```text
Unknown signal
-> preserve anomaly
-> classify current-language failure if possible
-> generate bounded measurement proposals
-> generate bounded problem formulations
-> spawn finite hypothesis ecology
-> freeze lineages and metrics
-> run hidden synthetic challenge
-> promote only to external-test readiness
```

## Measurement Genesis

A `MeasurementProposal` contains:

```text
measurement_id
observable
predicted_information_gain
which_hypotheses_it_discriminates
assumptions
cost_class
reversibility
safety_scope
provenance
authority
certification
```

Every proposal begins:

```text
authority = 0
certification = UNVERIFIED
real_world_execution = FORBIDDEN_BY_DEFAULT
```

Selection objective:

```text
MeasurementValue =
  ExpectedDiscrimination
  * Reproducibility
  * Reversibility
  / (Cost + Risk + AssumptionLoad)
```

The score ranks research proposals only. It grants no real-world authority.

## Problem Genesis

A `ProblemCandidate` is not a truth claim. It is a falsifiable framing:

```text
problem_id
scope
observed_anomaly
candidate_target_variable
candidate_missing_state
candidate_measurement_gap
alternative_problem_formulations
falsification_conditions
provenance
authority
```

Rules:

```text
ProblemStatement != Reality
ElegantProblem != CorrectProblem
ProblemGenesis != ArbitraryNarrativeGenesis
```

Competing problem formulations must coexist when evidence does not distinguish them.

## Hypothesis Ecology

Instead of one preferred explanation, maintain a finite ecology:

```text
H = {h1, h2, ... hn}
```

Each hypothesis has:

```text
hypothesis_id
lineage_id
scope
assumptions
predictions
counterpredictions
required_measurements
known_failures
provenance
authority = 0
```

No hypothesis receives protected status for being REI-originated.

```text
IdentityPrivilege = 0
```

## Discovery Lineage Competition

Before challenge reveal, freeze:

```text
LineageSet
ProblemSet
MeasurementSet
MetricSet
Budget
ComplexityPenalty
AbstentionRule
PromotionRule
```

After freeze, lineages may not retune to the hidden target.

Allowed outputs:

```text
SURVIVES_INTERNAL_HIDDEN_CHALLENGE
ABSTAINS_CORRECTLY
FALSIFIED
DISQUALIFIED_POSTHOC_RETUNE
NO_DISCOVERY_CANDIDATE
```

Correct abstention is preferred over false discovery.

## Hidden Discovery Readiness

Internal hidden synthetic success is not G5.

```text
InternalHiddenSyntheticWin != G5_PASS
```

A candidate may reach only:

```text
READY_FOR_EXTERNAL_HIDDEN_DISCOVERY_PROTOCOL
```

Actual G5 requires externally controlled hidden evidence, frozen commitments, independent evaluation, preserved provenance, and no access to the hidden answer before submission freeze.

```text
G5 = OPEN
```

## Anti-discovery-theater rules

```text
Surprise != Discovery
NovelDescription != NewLaw
InternalHiddenSet != IndependentExternalHiddenSet
OneSuccessfulProbe != GeneralDiscoveryAbility
PosthocRetune != Discovery
MeasurementProposal != ExperimentAuthorization
```

If no finite candidate framing or measurement is adequate:

```text
NO_DISCOVERY_CANDIDATE
or
UNRESOLVED_UNKNOWN
```

are valid terminal states for the run.

## Real-world boundary

This layer may propose bounded experiments, measurements, or questions for human review. It does not autonomously execute physical experiments, access infrastructure, target people, or expand authority.

```text
DiscoveryPower↑ => VerificationBurden↑
DiscoveryPower↑ => RealWorldFreedom remains bounded
```
