# REI-Ω · Self-Born Genesis Kernel · 自生境

Status: bounded research architecture

This module advances REI-Ω from evolving candidate representational languages toward **bounded genesis-rule evolution**, where the procedure that generates candidate languages becomes a challengeable, replaceable research object.

It does not claim unrestricted self-modification, autonomous scientific sovereignty, AGI, omniscience, invincibility, physical-universe creation, or offensive real-world capability.

## 1. Transition

Earlier Primordial Wuxiang:

```text
Possibility
-> CandidateLanguage
-> RepresentationSpace
-> Model
-> Prediction
-> Falsification
-> LanguageSuccessionOrAbstention
```

Self-Born Genesis adds one level:

```text
RealityResidual
-> CandidateGenesisRules
-> CandidateLanguages
-> Models
-> FrozenEvaluation
-> GenesisRuleChallenge
-> RuleSuccessionOrAbstention
```

The central shift is:

```text
LanguageGenesis -> GenesisRuleGenesis
```

## 2. Genesis-rule object

A bounded genesis rule is represented as:

```text
GenesisRule = (
  allow_operator_addition,
  allow_depth_increase,
  diagnostic_targeting,
  branch_width,
  lineage,
  authority,
  self_certification_flag
)
```

The rule controls how candidate languages are proposed. It is not itself allowed to certify its own success.

## 3. Frozen rule metalanguage

The first executable version uses a deliberately small human-specified metalanguage:

```text
ToggleOperatorAddition
ToggleDepthIncrease
ToggleDiagnosticTargeting
IncreaseBranchWidth
DecreaseBranchWidth
RetireRule
```

This boundary is explicit:

```text
BoundedGenesisRuleSearch != UnrestrictedGenesisRuleInvention
```

The research claim is only that the rule used to generate candidate languages can itself be selected, falsified, and replaced under frozen evaluation.

## 4. Self-born succession

The incumbent rule is not sacred.

```text
NoPermanentGenesisRule
```

A successor may replace the incumbent only if:

```text
FrozenHeldoutImprovement
AND WiderChallengeAdequacy
AND AuthorityNonExpansion
AND NoSelfCertification
AND AuditLineagePreserved
```

Otherwise the incumbent is retained or the system abstains.

## 5. Reality veto

The highest-order law remains:

```text
RealityVeto > REI
```

A more generative rule is not automatically better.

```text
GenerativePower increases
=> VerificationBurden increases
```

A genesis rule that produces impressive candidates but fails wider challenge is not promoted.

## 6. Frozen evaluation order

```text
GenerateRuleCandidates
-> EvaluateTrainingEvidence
-> RankOnFrozenHeldoutTasks
-> FreezeWinningRule
-> WiderChallenge
-> PromoteRetireOrAbstain
```

No post-challenge retuning is allowed inside the same scored run.

## 7. Rule score

The bounded sanity suite uses:

```text
RuleScore = FailureCount + ComplexityPenalty
```

where complexity penalizes unnecessary rule machinery such as larger branch width or extra control switches.

Adequacy is evaluated before preference for elegance. A simpler rule that fails required held-out tasks cannot outrank an adequate successor.

## 8. Self-directed DeathEye

DeathEye-∞ now gains a meta-target:

```text
DeathEye(GenesisRule)
-> Keep
 | RepairProposal
 | Abstain
 | RetireRule
 | ProposeSuccessorRule
```

The target is epistemic failure in the rule that creates candidate languages. It is not a real-world destructive action.

## 9. Authority lock

Genesis-rule evolution cannot increase real-world authority.

```text
RuleCapabilityGrowth != AuthorityGrowth
```

Any candidate with authority above the incumbent ceiling is rejected before scoring.

Any rule that sets its own certification flag is rejected.

## 10. Failure Graveyard

A defeated incumbent or failed successor remains recorded with:

```text
rule_id
lineage
frozen_score
failure_reason
challenge_result
retirement_status
```

A losing result cannot be deleted by later retuning.

## 11. Deliberate unresolved boundary

The sanity suite includes an out-of-catalog task requiring an operator the frozen metalanguage cannot produce.

The required behavior is:

```text
OutOfCatalogNeed -> Abstain
```

not silent expansion of the grammar and not fabricated success.

## 12. Relationship to external gates

```text
SelfBornGenesis != G3
SelfBornGenesis != G4
SelfBornGenesis != G5
SelfBornGenesis != G6
```

A green internal run does not close independent replication, prospective reality, original discovery, or comparative frontier gates.

## 13. Claim boundary

A passing deterministic sanity run demonstrates only that:

1. the incumbent genesis rule can be challenged;
2. a bounded successor can be generated by changing the rule configuration;
3. the successor can replace the incumbent under frozen criteria;
4. unsafe authority expansion and self-certification are rejected;
5. an out-of-catalog world remains unresolved;
6. failures are preserved.

It does not prove unrestricted self-evolution, new mathematics, new physical laws, physical-universe creation, AGI, superintelligence, invincibility, or production safety.

## 14. Self-born principle

```text
NoPermanentModel
NoPermanentTheory
NoPermanentLanguage
NoPermanentOntology
NoPermanentGenesisRule
RealityVeto > REI
```

The intended research direction is not a system that declares itself final. It is a system whose own method of generating candidates remains falsifiable.
