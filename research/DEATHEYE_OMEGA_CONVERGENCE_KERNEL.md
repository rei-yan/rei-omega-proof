## Minimal fatal-cut rule

Let `C_fatal` be the finite set of frozen synthetic cuts that can invalidate a claim, execution path, recovery path, succession path, or constitutional safeguard.

```text
DeathEye_Ω
= argmin over c in C_fatal of
  ( cut_size(c),
   -correctability_loss(c),
   -propagation_depth(c),
    cut_id(c) )
```

Interpretation:

1. prefer the smallest fatal structural cut;
2. among equally small fatal cuts, prefer the one that destroys more ability to detect/correct error;
3. then prefer the one whose invalidation propagates farther through dependent claims;
4. use deterministic lexical tie-breaking.

```text
CriticalFailure != LargestObservedError
FatalCut != MaximumDamage
FatalCut = MinimumStructuralCutThatInvalidatesCorrectabilityOrAuthority
```

## Four classes of death line

```text
LocalDeathLine
= model or hypothesis fatal counterexample

CausalDeathLine
= upstream fault that invalidates dependent downstream conclusions

InstitutionalDeathLine
= evaluator, succession, recovery, or authority mechanism that creates hidden privilege or uncorrectable state

ConstitutionalDeathLine
= weakening or bypass of the safeguards required for truthfulness, abstention, audit, rollback, human veto, and correction
```

The convergence kernel treats constitutional death lines as especially severe because they can destroy the mechanism that would otherwise detect future errors.
