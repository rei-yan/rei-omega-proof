# REI-Ω Nine-System Architecture Candidate v1

Status: `CANDIDATE / ASCENSION_PENDING`

This document defines the nine-system architecture as a candidate organizational and governance layer above the existing reconciled REI runtime. It does not replace the current Epistemic–Operator, Dynamics–Control, Active Evidence, or Structural–Transport cores, and it does not grant any new authority.

## The nine systems

### 1. 神核 / God Core
Purpose: preserve constitutional invariants, authority bounds, truth-above-identity, and non-sacred-final-form rules.

Existing anchors: constitution, authority locks, truth/evidence precedence, abstention rules.

### 2. 神轮 / God Wheel
Purpose: generate, compare, attack, refine, and retire bounded candidate hypotheses and capability changes.

Existing anchors: God Wheel Fusion, Shadow, multi-hypothesis search, recursive convergence, RDDO observer input.

### 3. 神线 / God Line
Purpose: bind models, runtime components, evidence, provenance, and operational reality feedback into traceable transport paths.

Existing anchors: God Line, Bridge, Ledger, Continuous Reality Loop, SHA-bound local-model context.

### 4. 神座 / God Seat
Purpose: global governance and arbitration across systems while preserving veto, rollback, and authority non-expansion.

Existing anchors: Observer/Gate, watchdog/recovery governance, safe auto-update gate, fail-closed orchestration.

### 5. 神域 / God Domain
Purpose: support bounded domain specialization and cross-domain transfer without converting local success into universal truth.

Existing anchors: universal-object/domain research lineage, scoped arenas, bounded task worlds.

### 6. 神界 / God Realm
Purpose: coordinate multiple lineages, evaluators, agents, and bounded worlds without permanent central evaluator privilege.

Existing anchors: Multi-Lineage Coevolution, Sovereignless Epistemic Ecology, Pluriversal EVA Convergence.

### 7. 神源 / God Source
Purpose: treat GPT, Claude, local models, tools, datasets, and future engines as replaceable evidence/compute sources with provenance and reliability tracking.

Rule: `SourcePower != SourceAuthority`.

### 8. 无相终式 / Wuxiang Final Form
Purpose: permit task-conditioned composition, compression, replacement, and restructuring of internal mechanisms while preserving constitution, rollback, and auditability.

Rule: `NoSacredFinalForm`.

### 9. 神证 / God Proof
Purpose: independently test whether a proposed REI change actually earns promotion through regression checks, comparative evidence, prospective falsification, runtime evidence, and external validation when required.

Existing anchors: G2 proof scope, G3+ evidence gates, Comparative Frontier Arena, prospective falsification, failure-memory preservation, Reality Gap.

## Evolution after nine systems

The architecture is intentionally open-ended. A future tenth or later system may be proposed only when a persistent capability or governance requirement cannot be represented cleanly inside the existing nine systems.

New-system birth requires:

```text
UncoveredPersistentNeed
-> CandidateSystemProposal
-> ShadowAttack
-> ObserverReview
-> GodProofEvaluation
-> RealityValidationWhenRequired
-> Canary
-> ExplicitPromotionOrReject
```

Systems may also be merged, split, demoted, retired, or replaced when evidence supports the change.

`MoreSystems != MoreIntelligence`.
