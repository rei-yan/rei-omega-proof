# REI-Ω∞ · Ontology Rupture, Causal Grammar Genesis & Multi-World Transfer

Status: **candidate research extension / not canonical**

Parent line: `REI-Ω∞ · 无相终式 · Representation Rupture Genesis`

This module extends the bounded Genesis route from representation primitives to the ontology and causal-grammar level. It does **not** create physical worlds, establish universal causality, authorize real-world intervention, or certify autonomous self-improvement.

## 1. Core reversal

A strong architecture must be able to question not only a model parameter or basis function, but also the object vocabulary used to describe the problem.

```text
NoPermanentVariable
NoPermanentObjectPartition
NoPermanentCausalGrammar
NoPermanentTransferClaim
RealityVeto > OntologyPreference
```

The goal is not unrestricted invention. The goal is bounded proposal generation followed by frozen falsification.

```text
OntologyRupture != ArbitraryObjectCreation
CausalGrammarGenesis != UniversalCausalKnowledge
TransferSuccessOnOneTarget != UniversalTransfer
```

## 2. Ontology rupture

An ontology is a finite candidate partition of observations into objects, states, or relations used by a model.

```text
OntologyCandidate = (
  ontology_id,
  source_failure,
  constructors,
  object_definitions,
  invariances,
  predicted_observables,
  falsification_conditions,
  provenance,
  authority,
  certification
)
```

Every generated ontology begins:

```text
authority = 0
certification = UNVERIFIED
canonical = false
```

Ontology rupture may be considered only after the current frozen representation family fails a challenge. The failure is preserved first.

```text
CurrentGrammarFails
-> PreserveFailure
-> DetectResidualStructure
-> EnumerateFinitePreauthorizedOntologyCandidates
-> FreezeCandidates
-> HeldoutEvaluation
-> WiderChallenge
-> KEEP_AS_CANDIDATE | ARCHIVE_FAILURE | ABSTAIN
```

If no eligible candidate survives:

```text
NoEligibleOntology => ABSTAIN
```

## 3. Causal grammar genesis

After an ontology candidate survives an internal frozen test, REI may enumerate a finite causal grammar over those objects.

Examples of safe epistemic candidates include:

```text
X -> Y
State(X) -> Y
X + State(X) -> Y
CommonCause -> {X, Y}
```

Observational fit alone never certifies direction.

```text
PredictiveFit != CausalIdentification
Correlation != InterventionEvidence
```

When two causal candidates are observationally indistinguishable:

```text
CausalDirectionUnidentified => ABSTAIN
```

Discriminating interventions are first tested only in synthetic or explicitly authorized experimental sandboxes.

```text
SyntheticIntervention
-> CandidateA prediction
-> CandidateB prediction
-> MaximumDisagreementPoint
-> FrozenOutcomeCheck
```

No real-world actuation authority is created by this module.

## 4. Multi-world transfer lattice

A candidate that succeeds in one digital world receives no automatic right to generalize.

```text
SourcePass != TargetPass
TargetPass != UniversalPass
```

A transfer claim must freeze all of the following before target evaluation:

```text
SourceWorld
Ontology
CausalGrammar
ParametersOrUpdateRule
TargetWorld
Metric
Tolerance
NoRetuningRule
```

The transfer cycle is:

```text
FreezeSourceCandidate
-> FreezeTargetWorld
-> EvaluateWithoutRetuning
-> OODChallenge
-> KEEP_SCOPE | NARROW_SCOPE | ABSTAIN | RETIRE
```

Silent hindsight adaptation is forbidden:

```text
TargetFailure
-> RetuneTarget
-> RewriteAsOriginalTransferSuccess
```

is invalid.

## 5. Regime-shift boundary

A representation may transfer across new samples while failing under a changed regime. This is evidence about scope, not an invitation to rewrite history.

```text
SameMechanismNewSamples -> may transfer
ChangedMechanism -> must be challenged
```

If a frozen ontology assumes a threshold at `0` and a target world shifts that threshold, the source claim must not silently expand.

```text
FrozenTransferFailsUnderShift
=> ABSTAIN or NARROW_SCOPE
```

## 6. Ontology and causal claim leases

High-impact ontology and causal claims inherit the evidence-lease rules.

```text
OntologyLeaseValid(t) =
```

Causal claims additionally require evidence appropriate to direction and intervention scope.
