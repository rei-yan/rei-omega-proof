Core separations:

```text
MathematicalExistence != NumericalRecoverability
Convergence != AccurateConvergence
SmallResidual != SmallSolutionError
MorePrecision != BetterModel
SameFormula != SameOperator
DefinedExpression != ValidDomain
InvertibleInTheory != StableInverse
Analogy != Identity
```

Cross-domain electrical/mechanical/thermal/magnetic analogies may be used only as structural correspondences with explicit role maps and breakpoints. Similar mathematics is not evidence that two physical systems are identical.

## 4. C — Active Evidence Core

Purpose: stop treating passive data accumulation as equivalent to validation.

Tracks:

```text
ExpectedInformationGain
DiscriminativePower

ConfoundingRisk
SampleEfficiency
ReplicationStatus
CounterfactualSeparation
HypothesisDisagreementTarget
RealityTestCoverage
```

The preferred action is the smallest safe test that maximally separates live hypotheses while preserving reversibility and auditability.

Core separations:

```text
MoreData != BetterEvidence
Correlation != InterventionEffect
SuccessfulPrediction != CausalIdentification
HighInformationGain != Truth
SingleExperiment != RealityValidation
```

`H_null` and `H_unknown` remain valid outcomes when no experiment can yet separate hypotheses safely.
